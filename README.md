# spla3gcal

スプラトゥーン3 のスケジュールを、誰でも購読できる公開 Google カレンダーとして配っています。バトルはマッチとルールの組み合わせごと、サーモンランは 1 つのカレンダーに分かれているので、遊びたいものだけを選んで購読できます。

## 予定の中身

- バトルの予定は、そのルールの枠の時間帯に入ります。
- サーモンランの予定の説明欄には、ステージ・オカシラシャケ・支給ブキを書いています。ビッグランの枠はタイトルが「サーモンラン ビッグラン」になります。
- 予定は 4 時間おきに足していき、先の予定はおおむね 1 日分まで入っています。
- フェス開催中はバンカラマッチなどの通常のルールの枠がないため、その間は予定が入りません。
- バイトチームコンテストは入れていません。

## データ元

[Spla3 API](https://spla3.yuu26.com)（非公式）のデータを使っています。API の仕様変更や停止で予定が入らなくなることがあります。
